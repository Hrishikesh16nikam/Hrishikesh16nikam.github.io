# hrishikesh16nikam.github.io

Personal portfolio of Hrishikesh Nikam, software engineer. Live at https://hrishikesh16nikam.github.io

```
index.html                     page content
style.css                      styles
js/main.js                     navigation and interactions
js/matrix.js                   background animation (pausable, respects reduced-motion settings)
assets/                        images, icons and link-preview image
Hrishikesh_Nikam_Resume.pdf    résumé
```

Plain HTML, CSS and JavaScript with no build step. To preview locally, run `python -m http.server` in this folder and open http://localhost:8000.

# hrishikesh16nikam.github.io

Personal portfolio site, served by GitHub Pages: https://hrishikesh16nikam.github.io

```
index.html        page structure and content
css/style.css     all styles (terminal theme, layout, animations)
js/main.js        boot screen, interactive terminal, navigation and effects
js/projects.js    project card boot animation
```

Plain HTML, CSS and JavaScript with no build step. To preview locally, run `python -m http.server` in this folder and open http://localhost:8000.
